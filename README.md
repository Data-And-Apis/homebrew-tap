# Crawlune Homebrew tap

Installs [Crawlune](https://crawlune.com/), the desktop SEO crawler, on macOS (Apple Silicon and Intel) and puts the `crawlune` command on your PATH for the CLI, the CI mode and the MCP server.

```sh
brew install data-and-apis/tap/crawlune
```

Upgrade with `brew upgrade --cask crawlune`. The app also updates itself from inside.

The cask is regenerated by Crawlune's release workflow from the signed release manifest; please do not edit it by hand. Questions: support@crawlune.com.
